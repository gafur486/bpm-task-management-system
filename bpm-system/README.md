# BPM Task Management System

Внутренняя система управления бизнес-процессами (Business Process Management) для банковской организации. Проект демонстрирует полный цикл frontend-разработки: аутентификация, ролевой доступ, CRUD-операции, интеграция с REST API, BPM-процесс согласования заявок и работа с реляционной базой данных PostgreSQL.

> Учебно-портфолио проект, имитирующий реальную внутреннюю систему банка.

---

## Возможности

- **Аутентификация** — вход по email/паролю, JWT-токен, защищённые маршруты, выход из системы.
- **Ролевой доступ (RBAC)** — три роли: `Admin`, `Manager`, `Employee`. Согласование заявок доступно только Admin и Manager.
- **Дашборд** — карточки статистики, распределение задач по статусам, последние задачи.
- **Управление задачами** — создание, редактирование, удаление, фильтрация и поиск. Статусы: New → In Progress → Review → Completed.
- **Справочник сотрудников** — поиск, серверная пагинация, страница профиля сотрудника.
- **BPM Workflow** — создание заявок, процесс согласования (Submitted → Approved/Rejected), история изменений (timeline).
- **Тёмная тема** — переключение light/dark с сохранением выбора.
- **Уведомления** — всплывающие toast-сообщения об успехе/ошибке.
- **Экспорт в CSV** — выгрузка списка задач.
- **Адаптивный дизайн** — корректная работа на мобильных и десктопе.

## Технологии

| Категория | Стек |
|-----------|------|
| Ядро | React 19, Vite |
| Стили | Tailwind CSS (тёмная тема через `class`) |
| Маршрутизация | React Router v6 |
| Серверное состояние | TanStack React Query |
| Клиентское состояние | Zustand (+ persist) |
| HTTP-клиент | Axios (с interceptors) |
| Mock REST API | json-server |
| База данных | PostgreSQL (schema.sql) |
| Качество кода | ESLint |

## Установка и запуск

```bash
# 1. Установить зависимости
npm install

# 2. Запустить mock REST API и фронтенд одновременно
npm run dev:all
```

После запуска:
- Фронтенд: `http://localhost:5173`
- REST API: `http://localhost:4000`

Можно запускать по отдельности: `npm run server` (API) и `npm run dev` (фронтенд).

## Структура проекта

```
src/
 ├─ api/         # Axios-клиент с interceptors (токен, обработка ошибок)
 ├─ components/  # Переиспользуемые компоненты (Modal, StatCard, формы и т.д.)
 ├─ pages/       # Страницы (Login, Dashboard, Tasks, Employees, Workflow)
 ├─ hooks/       # Кастомные хуки на React Query (useTasks, useEmployees...)
 ├─ store/       # Zustand-хранилища (auth, theme, notifications)
 ├─ layouts/     # Каркас приложения (Sidebar, Header, DashboardLayout)
 ├─ services/    # Сервисный слой API (CRUD-вызовы)
 ├─ routes/      # ProtectedRoute (защита + проверка роли)
 ├─ utils/       # Константы, форматтеры, экспорт CSV
 └─ types/       # Зарезервировано под типы
database/
 └─ schema.sql   # PostgreSQL: таблицы users, roles, tasks, requests + индексы
```

---

## Архитектурные решения

- **Сервисный слой** отделяет API-вызовы от UI — компоненты не знают про Axios напрямую.
- **Кастомные хуки** на React Query инкапсулируют загрузку, кэширование и инвалидацию данных.
- **Interceptors** в Axios централизованно подставляют JWT и обрабатывают 401 (авто-выход).
- **Состояния загрузки/ошибки/пустого списка** вынесены в отдельные переиспользуемые компоненты.
